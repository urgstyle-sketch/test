# Marlin — готовый сайт для хостинга

[Скачать архив сайта](./marlin-hosting.zip?raw=1)

Архив содержит готовый `index.html`, папку `assets` со всеми оригинальными видео, изображениями и локальными шрифтами, инструкцию на русском и автономный `offline.html`.

Распакуйте содержимое в папку сайта на хостинге (`public_html`, `www` или нужную подпапку). Файл `index.html` должен находиться прямо в этой папке. Устанавливать Node.js и запускать сборку на хостинге не требуется.

Формы демонстрационные: заявки и письма не отправляются. Для их отправки нужен отдельный обработчик.

Проверены запуск в корне сайта и в подпапке, загрузка всех медиа, перемотка двух видеороликов при прокрутке и автономная версия без внешних запросов.
